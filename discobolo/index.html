Club Discóbolo: Website and Automations

Club de Deportes Discóbolo is a tennis club in Haedo, Buenos Aires, founded on 25 May 1916. I build and maintain the club's website and the automations behind its day-to-day operations: member communication, payments, and reports.

Visit clubdiscobolo.com

The Club Website

clubdiscobolo.com is the club's public site, in Spanish: history, activities, Interclubes, contact details and opening hours, plus the privacy policy for the club's Google integrations.

  • Plain HTML and CSS with no build step, so it stays simple to maintain.
  • Deployed on Cloudflare Pages: every push to main publishes the site.
  • Self-hosted fonts and a strict Content Security Policy: no third-party requests.
  • Served from the club's own domain.

Automations

Weekly Interclubes email

Builds the weekend's matches from the Asociación Argentina de Tenis public fixtures. Reviewers check it first; then a GitHub Actions workflow sends it to members.

Birthday greetings

Sends members a greeting on their birthday, using the club's Google contacts and Gmail, on a schedule in GitHub Actions.

Payment workflow

Downloads bank transactions, updates the master Excel file and loads payments into the club's management system. Read the case study

Court-light charges

Records court-light usage, calculates monthly charges and uploads them safely. Read the case study

Debtor reminders

Sends personalized WhatsApp reminders to members with pending payments. View on GitHub

Committee reports

Generates the reports the club's committee uses to follow its operations.
